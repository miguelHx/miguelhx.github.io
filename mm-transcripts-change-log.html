Transcripts Update Instructions

If you have previous transcripts version and would like to update it, you will need to update your index on DocFetcher.

There's a few ways to do it. Can simply repeat the original setup steps but with the new folder(s).

Follow these steps to ensure correctness.

  1. Open DocFetcher and delete the MMTranscripts index by right clicking on it and selecting Remove Index.
    1. Note: If you created two separate indexes on TranscriptsTxt and TranscriptsSrt, make sure to remove both of them.
  2. Close/quit DocFetcher and make sure it is not running.
  3. Download and unzip the new MMTranscripts archive. (If you haven't already)
  4. Replace the old MMTranscripts folder with the newly unzipped one.
  5. Open up DocFetcher, and create a new index on folder, selecting the newly moved MMTranscripts folder. Or select TranscriptsTxt and TranscriptsSrt separately. Make sure to add srt to the Plain text field under File extensions:

  1. Click run

To verify update, check that newly created path from Change Log shows up. So, for 10/10/26 update, check that the path Facebook & Youtube/Videos/** exists when expanding folders on DocFetcher index.
