Taking a new course - Intro to CS and Programming using Python

Fri 19 December 2025 in Intro to CS using Python
#computer-science #python

Decided to take intro to CS using Python from MIT. Yes, this is easy basic stuff and my ego is nudging me to not proceed because “I already know this stuff”. And I feel like I’m already well-versed in Python, so why am I taking this course? Mostly out of curiosity. I want to see if there’s anything in the basics/fundamentals that I may have missed, and want to see if I learn something new despite having a lot of experience with Python and programming already.

I will be sharing what I learn and my thoughts throughout the course here on my blog with posts under the “Intro to CS and programming using Python” category.
